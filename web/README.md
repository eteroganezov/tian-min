# Тянь Мин — локальный web-MVP

Обработка места, исторического часового пояса и истинного солнечного времени описана в [METHODOLOGY.md](./METHODOLOGY.md).

Запуск из папки `web`:

```bash
npm run dev
```

После сообщения об успешном запуске откройте `http://localhost:3000`.

Сервер работает только на вашем Mac и использует существующий расчётный движок через его собранный JavaScript. По умолчанию локальная разработка не отправляет запросы в OpenAI; исключение возможно только после явного opt-in ниже.

## Безопасность OpenAI в локальной разработке

`web/server.cjs` загружает локальный `web/.env`, но одного `OPENAI_API_KEY` недостаточно для выбора реального OpenAI provider. По умолчанию development использует `AI_MODE=mock` либо безопасно сообщает, что AI недоступен.

Чтобы намеренно разрешить реальную локальную генерацию, одновременно задайте ключ, модель и явный opt-in:

```text
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-5.6-terra
ALLOW_REAL_OPENAI_LOCAL=true
```

Это создаёт реальные платные API-вызовы. `npm test` всегда запускается с `NODE_ENV=test` и блокирует real provider даже при случайно унаследованных ключе и opt-in. В production локальный флаг не требуется: production preflight по-прежнему требует реальную OpenAI-конфигурацию и запрещает `mock`/`disabled`.
