# Тянь Мин — локальный web-MVP

Запуск из папки `web`:

```bash
npm run dev
```

После сообщения об успешном запуске откройте `http://localhost:3000`.

Сервер работает только на вашем Mac, вызывает `calculator/local-chart.ts` через его собранный JavaScript и не отправляет данные во внешние сервисы.
